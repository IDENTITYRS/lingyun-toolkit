字字动画的作品级三合一插件。在作品插件中打开本插件，通过顶部“选择插件功能”下拉框切换：

| 下拉选项 | 功能 |
| --- | --- |
| 导入提示词 | 粘贴全文，按空行分段，依次写入分镜的视频提示词；分镜不足时自动新增。 |
| 导入资产 | 选择包含角色、场景、物品子目录的总目录，扫描预览后按图片文件名导入；跳过同类型已有名称或别名。 |
| 一键匹配图片 | 提供“全文匹配”和“指定匹配”两种模式；指定匹配按用户填写的词语（如“人物、场景”）筛选对应文字行，再匹配角色、场景、道具名称及别名。两种模式均长名称优先、忽略中英文双引号对白，更新参考图选中项。 |

切换功能保留当前页面已填写内容和执行结果。运行期间暂时禁用切换及重复提交；执行结束后恢复。重新打开时恢复上次选择的功能和资产目录，分镜正文不持久化保存。

顶部官方简介区保留容器，插件加载后隐藏重复标题和说明，压缩为 2px。此调整随 `ui/compact-host.js` 分发，只作用于本插件所在的作品面板，退出插件时恢复；下拉列表名称不变。不修改宿主文件；若其他版本隔离了 iframe 的同源访问，则保留其默认简介区。

## 使用

1. 本文件夹已位于软件的 `plugins/tool_plugins/project` 目录。
2. 刷新软件插件列表；若未出现，重启软件后在工具插件管理中启用“凌云·字字实用插件大全”。
3. 打开作品，进入作品插件面板并选择本插件。在页面底部复制机器码，取得对应激活码后粘贴并点击“激活”。
4. 右上角显示绿色“已激活·到期日期”或“已激活·永久”后，在下拉框选择功能，填写参数后执行。

分镜导入会替换目标字段的内容。图片匹配会替换目标分镜的参考图选中项，没有命中的类别会清空选中。全文匹配扫描整段提示词；指定匹配只扫描包含指定词的文字行，多个词用顿号“、”分隔。资产导入由宿主创建实体、复制图片并刷新作品。

资产目录示例：

```text
我的作品/
├─ 角色/陈平.png
├─ 场景/城门.webp
└─ 物品/长剑.jpg
```

支持 PNG、JPG、JPEG、WEBP、BMP；分类目录下可继续放子目录。支持人物、地点、道具及原插件中的英文分类名称。修改路径后必须重新扫描；导入结束后再次扫描可核对剩余资产。

## 代码结构与依赖

```text
main.py                      统一 UI 动作路由、execute 与 self_test
plugin.json                  插件标识、参数与合并后的能力权限
ui/index.html                单一界面、下拉切换、三个功能面板
ui/host-bridge.js            新版 Promise 与旧版 onAction 回调兼容
lingyun_features/sections.py 移植的分镜导入完整源码
lingyun_features/assets.py   移植的资产导入完整源码
lingyun_features/mapper.py   移植的提示词匹配完整源码
lingyun_features/license_manager.py 机器码、验签、到期与续期管理
lingyun_features/license_public.json 仅含签名公钥
tests/test_toolkit.py        使用模拟宿主的离线回归验证
tests/test_license.py        授权、续期、防重复与门禁回归
```

三个功能模块随本插件一起分发，不读取、不加载原三个插件目录，也不调用原插件入口。保留了原模块的自检。宿主的 PluginSDK、ToolClient 和 zzdh_* 内置接口仍由字字动画提供，无需额外安装 Python 包。分镜和匹配模块保留原来通过宿主 ToolClient 调用的兼容路径。

离线验证：在本目录运行 `python -m unittest discover -s tests -v`。测试使用临时图片与模拟工具，不改动实际作品。插件内 `self_test` 还会对宿主做一次只读分镜查询。

通信兼容测试：`node --test tests/test_host_bridge.js`。浏览器预览页 `tests/preview_host.html` 提供新版、旧版 SDK 切换；旧版模式模拟 `sendAction()` 无返回值、结果通过 `onAction()` 回传，需经本地 HTTP 服务打开。

## 激活与续期（1.1.0）

- 月卡 30 天、年卡 365 天、永久、自定义日期四档。
- 自定义日期在签发时减去签发当天，换算成天数；使用时和月卡、年卡一样累加。
- 未到期从现有到期时刻累加，已到期从激活时刻重新起算；一天为 24 小时。右上角显示到期日期，悬停和激活提示显示具体到期时间。
- 同一个激活码不能重复累加。永久授权不会被普通码覆盖或降级。
- 未激活或已到期时，UI 按钮和后端 `handle_action` / `execute` 都阻止业务操作。授权状态查询和激活本身不受限制。
- 本地记录保存在当前账户 `%LOCALAPPDATA%\Lingyun\lingyun_practical_toolkit\license.dat`，使用 Windows DPAPI 保护；不会写进作品文件。机器码由 Windows MachineGuid 派生。
- 这是离线授权，防重复依赖本地记录保留；不能抵御修改 Python 源码、删除/回滚全部授权记录或克隆系统，不能远程撤销。切换 Windows 账户或重装系统可能需要重新授权。
- 秘钥器和私钥单独保存在管理员指定目录，插件内部仅有公钥。发布时不要携带秘钥器或私钥。
