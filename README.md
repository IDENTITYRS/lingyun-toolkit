# 凌云·字字实用插件大全 V4.1.0

字字动画作品级工具插件：导入提示词、导入资产、按提示词匹配参考图片。顶部下拉切换功能，保留当前输入与结果。

## 安装与使用

1. 从 [GitHub Releases](https://github.com/IDENTITYRS/lingyun-toolkit/releases/latest) 下载 `lingyun-toolkit-4.1.0-install.zip`。
2. 退出字字动画，解压到软件的 `_internal/plugins/tool_plugins/project` 目录。保留一个本插件目录，避免重复显示。
3. 重启软件，在作品插件中选择“凌云·字字实用插件大全”。复制底部机器码并使用对应激活码激活。
4. 选择功能并执行。提示词导入和参考图匹配会修改作品中的目标分镜。

| 功能     | 使用方式                                                        |
| ------ | ----------------------------------------------------------- |
| 导入提示词  | 按空行拆分文本，依次写入分镜视频提示词，不足时新增分镜。                                |
| 导入资产   | 选择包含角色、场景、物品子目录的总目录，扫描预览后按文件名导入；跳过同类已有名称或别名。                |
| 一键匹配图片 | 全文匹配整段提示词；指定匹配仅处理包含所填词的文字行。均长名称优先，忽略中英文双引号对白。未命中的类别会清空本次选中。 |

## 版本更新

“版本更新”位于功能区下方、激活区上方，默认折叠，右侧显示当前版本。每次启动字字动画后首次打开插件会后台检查一次，也可以手动检查。检查只获取版本和说明，不自动安装。

发现新版后显示更新按钮与新增版本说明。“历史更新记录”默认折叠，左右箭头一次查看一个版本；首尾按钮自动禁用，长说明在固定高度内滚动，刷新时保留正在查看的版本。

点击更新后下载程序包，验证独立 RSA 签名、整体及各文件 SHA-256。独立“凌云插件更新助手”出现后，保存作品并完全退出字字动画，助手会自动安装。完成后重启软件。失败时恢复原程序；异常中断的安装在下次启动时恢复。网络失败时可检查网络或代理，再点击检查更新。

更新沿用原目录，保留机器码、授权、到期时间和个人设置。客户端只请求 GitHub 公共发布文件，不上传授权记录或作品数据。V4.0.0 轮换了自动更新签名密钥；V3.0.0 及更早版本需手动安装 V4.0.0 完整包一次。更新签名密钥与激活密钥独立，发布包只包含公钥。

## 授权

支持月卡、年卡、永久及自定义天数，未到期从现有到期时间累加，已到期从当前时间起算，同一激活码不能重复续期。授权保存在当前账户 `%LOCALAPPDATA%\Lingyun\lingyun_practical_toolkit\license.dat`，由 Windows DPAPI 保护。沿用原机器码算法、公钥和授权位置，不需要重新签发激活码。

## 开发与验证

- `main.py` 是固定启动入口，自动更新中必须保持字节不变；业务路由在 `lingyun_main.py`。
- `lingyun_features/` 包含三项功能和授权管理；`ui/` 包含界面、新旧宿主通信桥和更新面板。
- `lingyun_update*.py` 是参考 UPdream V2.5.0 移植的后台检查、签名校验、恢复事务及独立更新助手。
- `plugin.json` 是版本源；累计版本说明维护在 `CHANGELOG.md`。
- `python -m unittest discover -s tests -v`：业务、授权、签名校验、升级、拒绝降级、个人数据保留、失败恢复和网络失败回归。
- `node --test tests/test_host_bridge.js tests/test_update_panel.js`：新旧通信和更新面板交互回归。
- 本地模拟界面为 `tests/preview_host.html`，需从插件根父级提供本地 HTTP 服务以加载宿主 SDK。

## 发布

更新版本、更新日志并通过测试后，运行 `python tools/build_release.py`。输出在 `dist/v版本号/`：自动更新 ZIP、手动安装 ZIP、`update.json` 和 `update.sig`。签名私钥保存在发布电脑指定的外部 PEM 文件，不放入仓库或安装包；V4.0.0 之后的发布必须继续使用同一把私钥。

将上述四个文件发布到 `IDENTITYRS/lingyun-toolkit` 的 `v版本号` Release，并标记为最新版。安装包不包含开发测试、测试授权夹具、私钥或个人数据。
