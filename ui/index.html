选择插件功能

批量写入分镜提示词

每段内容对应一个分镜，段落之间用空行分隔；分镜不足时自动新增。

当前可识别 0 段

执行后将替换目标分镜对应字段的内容。

粘贴内容后点击导入。

批量导入资产图片

按文件名创建角色、场景、道具；同类型同名资产自动跳过。

总目录内放置“角色 / 场景 / 物品”子文件夹，也支持“人物 / 地点 / 道具”和英文目录名。支持 PNG、JPG、JPEG、WEBP、BMP。

尚未扫描目录
选择文件夹后，先扫描预览，再导入资产。

按提示词匹配参考图片

按分镜提示词匹配角色、场景、道具资产，并更新分镜左侧参考图选中项。

只匹配包含这些词的文字行，再从这些行中匹配资产名称。例如“人物、场景”会匹配【出场人物】和【场景地点】所在行。

全文匹配扫描整段提示词；指定匹配只扫描包含匹配词的行。均按长名称优先，并忽略中英文双引号内的对白。

请先导入对应资产；没有命中的类别会清空本次选中。

设置分镜范围后开始匹配。
